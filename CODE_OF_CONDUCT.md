# Code of Conduct

This project follows the [GNOME Code of Conduct](https://conduct.gnome.org/).

By participating in this repository, issues, pull requests, and related discussions, you agree to uphold that Code of Conduct.

Reports related to GNOME community spaces should follow the process at https://conduct.gnome.org/.

For project-specific concerns in this repository, open an issue or contact the maintainer via the repository URL in `metadata.json`.
